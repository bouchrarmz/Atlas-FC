# TACHKILA
Atlas FC est une application web interactive destinée à un club de football amateur. Elle permet à l'entraîneur de gérer son effectif et de préparer sa composition d'équipe selon le système tactique 4-4-2.

L'application propose une interface dynamique pour ajouter, modifier et supprimer des joueurs, les placer sur un terrain schématisé et respecter les règles de compatibilité entre les postes et les positions.
#  Technologies utilisées
HTML5 ,Tailwind CSS ,CSS3 ,JavaScript ,Git et GitHub , Vercel
